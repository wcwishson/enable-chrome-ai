# Release Notes

## v1.2.0 - Windows click-to-run app

This release adds a Windows app for people who just want to download, double-click, and try to restore Chrome AI.

### What's New

- Added `EnableChromeAI.exe`, a one-click Windows app.
- The app closes Chrome, applies the Chrome AI availability fix, and reopens Chrome automatically.
- The app shows a warning when Chrome may still be blocked by account or region checks.
- Added a Windows release bundle with the app, license, and a short user guide.
- Updated README files for non-technical users.

### How to Use

1. Download `EnableChromeAI-Release.zip` from the GitHub release page.
2. Unzip it.
3. Double-click `EnableChromeAI.exe`.
4. Allow the app to restart Chrome when prompted.
5. Check whether Gemini / Chrome AI is available again.

### Notes

- This app is for Windows users with Google Chrome installed.
- If Chrome updates and Gemini disappears again, run the app again.
- The app cannot guarantee availability for every Google account, Chrome version, or network region.
- The app does not collect your data or upload your Chrome profile.
